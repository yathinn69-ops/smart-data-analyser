# Smart Data Analyser

A Python-based data analytics project that cleans, analyses, and visualizes sales data to generate useful business insights.

## 📌 Overview

Smart Data Analyser processes sales data and converts raw information into useful insights through data cleaning, analysis, and visualization.

## 🚀 Features

- CSV data loading
- Data cleaning
- Missing-value handling
- Revenue analysis
- Product performance analysis
- Category-wise analysis
- Monthly sales trend analysis
- Automated CSV results
- Data visualization

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
